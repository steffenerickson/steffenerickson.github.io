mvgstudy

Stata
psychometrics
generalizability theory
Stata commands for multivariate generalizability and decision studies: variance/covariance component estimation with bootstrap BCa inference, D-study projections, and reliability criteria for LLM-classifier measurement designs.

Version 1.3.3 · GitHub · Issues

What it does

mvgstudy estimates variance and covariance components for multifaceted generalizability (G-study) designs, following Brennan (2001). It supports any combination of crossed and nested facets, univariate and multivariate outcomes, balanced and unbalanced designs, and data with missing outcome values. For balanced designs it uses the SSCP-based method-of-moments estimator derived from a MANOVA decomposition; for unbalanced designs it automatically switches to the exact CP-terms estimator (Brennan, 2001, Sec. 11.1.3), solving the linear system directly with no harmonic-mean approximation.

Existing Stata options for G-theory stop at univariate, balanced designs and point estimates. mvgstudy adds three things researchers routinely need: multivariate designs (full covariance component matrices for each effect, not just variances), exact handling of unbalanced data (unequal cell sizes and missing observations, detected and handled automatically), and statistical inference — bootstrap standard errors and bias-corrected accelerated (BCa) confidence intervals via cluster-level resampling of any facet or combination of facets, following the Li et al. (2023) taxonomy of bootstrap units.

The package ships as a suite of three commands:

Command Purpose
mvgstudy G-study: variance and covariance component estimation, with optional bootstrap
mvdstudy D-study: projects reliability coefficients (Eρ², Φ) and error/true-score variances over proposed facet sample sizes, with bootstrap CIs propagated from the G-study
mvcrr Projected construct-relevant reliability (CRR) for LLM-classifier measurement designs, with optional bootstrap BCa CIs

Installation

From GitHub:

net install mvgstudy, from("https://raw.githubusercontent.com/steffenerickson/mvgstudy/main/") replace

Requirements: Stata 16 or later. No dependencies outside official Stata.

Quick start

A fully-crossed persons × items × raters design with two outcomes:

use mvgstudyexampledata.dta, clear
mvgstudy (x1 x2 = p i h p#i p#h i#h p#i#h)

For fully-crossed or purely-nested designs, only the residual term is needed — the full termlist is expanded automatically:

mvgstudy (x1 x2 = p#i#h)     // expands to p i h p#i p#h i#h p#i#h
mvgstudy (x1 = p|i|h)        // expands to h i|h p|i|h

Main features

Multivariate covariance components

When the outcome list contains multiple variables, each effect gets a full covariance component (EMCP) matrix rather than a scalar variance, supporting multivariate G-theory analyses such as composite reliability and profile dependability.

Unbalanced designs, handled exactly

Unequal cell sizes are detected automatically and estimated with the exact CP-terms method — unbiased and consistent, with a documented fallback (and warning) to the harmonic-mean approximation only when the coefficient matrix is rank-deficient. Eight canonical designs (p×i, i:p, p×i×h, p×(i:h), (i:p)×h, i:(p×h), (i×h):p, i:h:p) are validated against hand calculations under both balance and random missingness.

Bootstrap inference

The bootstrap option adds standard errors and BCa confidence intervals for every component via cluster-level resampling. The resampling unit is any facet or set of facets (bootunit(p), bootunit(p i), …), with within-parent-group resampling for nested facets. The stored bootstrap distribution propagates automatically to mvdstudy, so D-study reliability projections carry confidence intervals too:

mvgstudy (x1 x2 = p i h p#i p#h i#h p#i#h), bootstrap reps(1000) seed(42)
mvdstudy, object(p) errortype(relative) current bootstrap ci_level(95)

Decision studies and LLM measurement designs

mvdstudy projects generalizability and phi coefficients over hypothetical facet sample sizes — the classic “how many raters and lessons do I need?” question. mvcrr extends the framework to LLM-classifier scoring systems, computing the projected construct-relevant reliability criterion developed in Chapter 2 of my dissertation.

Projecting CRR with mvcrr

mvcrr is a post-estimation command. It reads a G-study fit to exactly three per-cell outcomes: the classifier’s estimated false-positive intercept (Ahat), class separation (Jhat), and prevalence (pihat), each computed upstream from gold-labeled utterances. It then projects construct-relevant reliability for the facet sample sizes you plan to collect.

Persons with replicated lessons. Fit the nested persons-with-lessons design, then project to four lessons per teacher. The current option projects at the observed sizes instead, and bootstrap carries BCa confidence intervals through from a bootstrapped G-study:

use mvcrrexampledata.dta, clear
mvgstudy (Ahat Jhat pihat = p l|p)
mvcrr, object(p) nfacet(l 4)

mvgstudy (Ahat Jhat pihat = p l|p), bootstrap reps(1000) seed(90210)
mvcrr, object(p) nfacet(l 4) bootstrap

Two random facets. With persons crossed by lessons and raters, give every non-object facet a D-study size. Naming a facet in fix() instead treats it as fixed, so its differential classifier functioning is charged against validity rather than averaged out as error:

use mvcrrexampledata_plr.dta, clear
mvgstudy (Ahat Jhat pihat = p l r p#l p#r l#r p#l#r)
mvcrr, object(p) nfacet(l 4 r 2)
mvcrr, object(p) nfacet(r 2) fix(l 4)

The projected CRR, its zero-covariance version, λ, and the underlying reliability coefficients are returned in r(). Run mata drop c when finished.

Full syntax, options, termlist-expansion rules, and validated-design tables are in the help files (help mvgstudy, help mvdstudy, help mvcrr) shipped with the package.
