Project construct-relevant reliability (CRR) for a planned study using scores aggregated from LLM classifiers. 
function reliability({J, s2pi, s2piLP, eps2, nL, mupi, saP = 0, sjP = 0, saLP = 0, sjLP = 0}) {
  const st2  = J * J * s2pi + saP + sjP * (mupi * mupi + s2pi);
  const sLP2 = saLP + (J * J + sjP) * s2piLP
             + sjLP * (mupi * mupi + s2pi + s2piLP) + eps2;
  const rho    = st2 / (st2 + sLP2 / nL);
  const lambda = (J * J * s2pi) / st2;
  const crr    = (J * J * s2pi) / (st2 + ((J * J + sjP) * s2piLP + eps2) / nL);
  return {rho, lambda, crr, st2, sLP2};
}

// Within-lesson realization error for a hard classifier (draft Eq. for eps-bar^2):
// A = 1 - sp, J = se + sp - 1, nu1^2 = se(1-se), nu0^2 = sp(1-sp)
function epsHard({se, sp, mupi, n}) {
  const J = se + sp - 1;
  const nu1 = se * (1 - se), nu0 = sp * (1 - sp);
  return (mupi * nu1 + (1 - mupi) * nu0 + mupi * (1 - mupi) * J * J) / n;
}

CRR projection calculator

What each lever does

Each lever above changes one ingredient of the projected reliability of teacher-level scores aggregated from an LLM classifier.

  • Person DCF in intercept \(\sigma(a_p)\): how much the classifier’s false-positive rate varies systematically from teacher to teacher, adding reproducible error that looks like a real difference in practice.
  • Person DCF in separation \(\sigma(j_p)\): how much the classifier’s ability to distinguish the practice from everything else varies from teacher to teacher, scaling some teachers’ scores up or down across all their lessons.
  • Lesson DCF in intercept \(\sigma(a_{pl})\): how much the false-positive rate drifts from lesson to lesson within a teacher, adding error that averages out as more lessons are sampled.
  • Lesson DCF in separation \(\sigma(j_{pl})\): how much the classifier’s discriminating power drifts from lesson to lesson within a teacher, also averaging out with more lessons.
  • Sensitivity \(se\): the share of true instances of the practice the classifier correctly flags.
  • Specificity \(sp\): the share of non-instances the classifier correctly leaves unflagged.
  • Mean prevalence \(\mu_\pi\): how often the practice occurs on average across teachers, which sets the base rate the classifier is working against.
  • SD of person prevalence \(\sigma_\pi\): how much teachers truly differ from one another in how often they use the practice, the signal the score is meant to capture.
  • SD of lesson prevalence \(\sigma_{\pi,L:P}\): how much a teacher’s use of the practice varies from lesson to lesson, the occasion noise that more lessons average away.
  • Segments per lesson \(n\): how many transcript segments the classifier scores in each lesson, which governs the within-lesson realization error.
  • Lessons per person \(n_L\): how many lessons are scored for each teacher, which governs how much lesson-level error is averaged out.
